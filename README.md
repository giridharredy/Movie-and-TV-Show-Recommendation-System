# Movie Recommendation System

A content-based movie recommendation system built using Python, TF-IDF Vectorization, and Cosine Similarity.

## Features

- Recommends similar movies and TV shows
- Uses NLP preprocessing
- TF-IDF based feature extraction
- Cosine similarity for recommendations

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- NLP preprocessing

## Workflow

1. Data Cleaning
2. Text Preprocessing
3. Bag of Words / TF-IDF
4. Cosine Similarity
5. Recommendation Engine

## Example

Input:
```python
recommend("Kota Factory")
```

Output:
- Aspirants
- Hostel Daze
- TVF Pitchers

## Installation

```bash
pip install -r requirements.txt
```

## Run Project

```bash
python app.py
```
